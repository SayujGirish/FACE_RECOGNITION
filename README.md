# Face Recognition using OpenCV and YOLO

A real-time face recognition project built with Python, OpenCV, and YOLO.

## Features

- Real-time face detection
- Custom face dataset creation
- Face recognition
- Live webcam inference.

## Tech Stack

- Python
- OpenCV
- YOLO
- NumPy

## Workflow

Webcam → Face Detection → Face Recognition → Display Result
